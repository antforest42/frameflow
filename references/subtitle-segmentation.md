# 语义断句与音频优先字幕

`subtitles.srt` 只用于画面烧录。朗读由带完整标点的 `normalized_script.txt` 直接通过曼波 API 连续生成，不再让剪映依据短显示字幕逐条生成语音。

## 处理顺序

1. 把用户原始换行视为不可信排版，合并误换行、重复空格和聊天复制碎片。
2. 分离标题与正文。标题用于可选片头、封面、正文左上角页眉和 `plan.json`；首段若重复标题，从正文移除，标题始终不进入显示字幕或朗读。
3. 在不增删、替换或调换原文字词的前提下，根据语义恢复句子和标点，只把正文写入 `normalized_script.txt`。
4. 先理解主谓宾、修饰、并列、转折、因果和递进，再按屏幕阅读节奏切成 `subtitle_lines.txt`。
5. 保留行内顿号、逗号、引号、冒号等，只删除每条字幕末尾的逗号、句号、问号、感叹号、分号、冒号、顿号、省略号或破折号。
6. 运行 `sync_subtitle_punctuation.py` 从正文确定性恢复内部标点，再运行 `make_srt.py`。
7. 使用完整正文生成 API 朗读，先取得词级时间戳，再运行 `align_from_word_timestamps.py` 强制对齐原文；仅在识别不可用时才用 `align_audio_timeline.py` 作为备用。
8. 连续默读全部相邻字幕。显示边界只影响换字，不决定朗读停顿。

## 显示字幕切分

- 目标长度5—11个有效汉字，允许3—14字。
- 语义或韵律完整优先于字数。
- 优先在完整句末、从句末、并列项、转折或因果转换处切分。
- 保持否定词或能愿词＋动词、动词＋核心宾语、介词＋宾语、数量词＋名词、专名、固定搭配和偏正短语完整。
- 不要让上一条以“不会、不能、需要、因为、如果、只要、一到、把、被、对、和”等悬空成分结束。
- 枚举和引用中的内部标点必须保留，例如“春招、秋招、上岸”“大厂、中小厂、学历”和“看见‘卷’这个字”。
- 第一条字幕必须是正文第一句，不能重复标题。

已确认可用：

```text
普通家庭
根本不会教孩子社交
为啥很多人
一到社交场合就犯怵
不会说话
不懂拒绝
总被人拿捏
```

禁止：

```text
普通家庭根本不会
教孩子社交

为啥很多人一到
社交场合就犯怵
```

## API 自然分段不是显示字幕

接口单段默认不超过260字符。优先在句号、问号、感叹号、分号和主题段落处拆分，必要时再用逗号、冒号或顿号。API 分段只为满足接口和断点续用：

- 不按显示字幕逐条请求；
- 不在段间插入固定空白；
- 每段结尾必须是自然语义边界；
- 合并后仍是一条连续朗读。

## 计时

`privacy_reference_v1` 只用于生成朗读前的临时检查：

- 30fps；
- 第一条从第118帧开始；
- 每条 `max(25, 4 + 5 × 有效汉字数)` 帧；
- 间隔按0、1帧循环。

朗读生成后必须优先改为 `audio_aligned_v2`：

- 第一条仍从第118帧开始；
- 边界以真实停顿和文字位置为准；
- 相邻字幕连续换字，不额外制造空白；
- 最后一条与朗读结尾对齐。

`audio_aligned_v1` 只保留为词级识别不可用时的停顿插值备用方案，必须经过人工同步抽检。

## 质检

- 忽略空白和标点后，`normalized_script.txt`、`subtitle_lines.txt` 和SRT必须完全相同。
- `normalized_script.txt` 首段不得等于标题。
- 不得漏字、增字、改写或调换顺序。
- 不得因达到字数上限切开紧密语法结构。
- 发现换字边界不自然时先改显示切分，不通过增加朗读空隙掩盖。
